# 使用 CompIntel3

## 第一次对弈

打开“对弈工作台”，选择五子棋或路墙棋。双方棋手都可以独立选择：

- **我来下棋**：通过棋盘操作。两方都选此项时可以在同一台电脑轮流练习。
- **内置棋手**：不需要安装编译器，直接使用内置策略对弈。
- **已编译的程序版本**：在“程序实验室”编译成功后出现在列表中。

点击“开始对局”。五子棋点击棋盘交叉点落子，**白方先行**。路墙棋在“移动”模式点击标记的合法落点；选择“横墙”或“竖墙”后，点击四格之间的标记的交叉点放墙。

“结束对局”会关闭本局的玩家进程并保存已有行动。正常分出胜负、达到规则上限、程序运行失败和非法输出也会自动结束并存档。没有任何行动的手动取消局不生成回放。

“悔棋”适用于双人练习以及与内置棋手对弈；人机对战会撤回到人类的上一个回合。自定义程序维护自己的内部状态，因此这些对局不提供悔棋。

## 编写自己的棋手

1. 打开“程序实验室”，选择游戏并填写程序名称。
2. 编辑默认示例，或导入 UTF-8 `.cpp`、`.cc`、`.cxx`、`.txt` 源码。单份源码最多 256 KiB。
3. 点击“编译并保存版本”，或按 `Ctrl+B`。右侧显示编译诊断。
4. 编译成功后，返回工作台，在先手或后手列表中选择该程序版本，然后开始对局。
5. 同时为双方选择程序，即可观看程序互战；同一个程序也可同时担任两方，每方使用独立进程。

默认自动检测 Visual Studio 的 x64 MSVC 工具链。也可以在“设置”填写 `cl.exe`、`clang++` 或 `g++` 的路径。仅与内置棋手对弈不需要编译工具链。

每次成功编译都会生成新的源码版本与独立产物。点击右侧历史版本可把其源码载入编辑器继续修改；再次编译会创建新版本。`Ctrl+S` 可以立即保存草稿，草稿也会定期自动保存。载入示例前会在数据目录备份当前非空草稿。

程序在整局中持续运行。请使用标准输入读取数据，向标准输出写入一行合法行动，并用 `std::endl` 或 `std::flush` 刷新。调试信息写入 `std::cerr`。协议和示例见 [protocol.md](protocol.md) 与 [`examples/`](../examples/)。

## 回放与数据

在“对局回放”中选择已保存的对局。使用滑条、单步按钮或“播放”逐步重建棋盘。“导出”生成 CompIntel3 v1 JSON 回放；“导入回放”会逐步检查每个行动是否合法，再加入本地档案。回放记录不包含可执行程序。

程序版本、源码草稿、设置、回放和编译产物默认位于 `%LOCALAPPDATA%\CompIntel3`。在“设置”中点击“打开数据目录”查看。可备份整个目录以保留本地资料。应用采用单实例运行，避免多个窗口同时覆盖资料库。

本机 Player 使用当前用户权限运行。资源限制与错误处理用于本地调试，不提供文件和网络安全隔离。具体行为见 [architecture.md](architecture.md)。

## 外观与导航

侧边导航会随窗口宽度自动展开或收起，点击左上角菜单按钮可展开导航。“设置 → 应用主题”提供跟随 Windows、浅色与深色三种选项，选择后立即预览，点击“保存设置”记住选择。首次使用默认跟随 Windows；已有资料库保留之前明确选择的主题。控件、强调色和棋盘使用 Windows 与 WinUI 官方主题资源。
