# Player 交互协议

CompIntel3 沿用参考 CompIntel 的 v1 文本协议。用户可以在程序工坊编写 C++20 程序，编译为本地可执行文件，再让它与人类、内置 Player 或其他已编译版本对战。两个游戏都使用**一局一个持续运行的进程**：程序保存自己的棋盘，每回合接收对手刚完成的一步，再输出自己的行动。

协议使用 UTF-8 文本、十进制非负整数和 ASCII 空白；除整数 `0` 本身外，数值不能带前导零。标准输出只写行动，每步恰好一行，并立即刷新；调试内容写入标准错误 `std::cerr`。不能在标准输出打印提示词、棋盘或日志。先手读取初始化后立即行动；后手读取初始化和对手第一步后行动。获胜一步完成后不会再要求对手行动。对局结束或被取消时，运行器终止程序，不发送结束标记。

## 五子棋 Gomoku

固定为 15 × 15 棋盘，坐标均为 `0..14`。本版本沿用参考项目的席位定义：**席位 0 执白并先手，席位 1 执黑并后手**。双方交替落子，横向、纵向或任一斜线连续五子或更多即获胜，无禁手；棋盘填满仍无人获胜则平局。

启动时标准输入为三行：

```text
1
15 15
S
```

其中 `1` 是协议版本，`S` 为己方席位 `0` 或 `1`。每次接收对手走法及输出自己的走法都使用：

```text
X Y
```

目标必须在棋盘内且为空。每行必须恰好两个整数，多余字段、负数、小数、科学计数法、越界或重复落子都会判为非法行动。

例如，后手程序可能收到：

```text
1
15 15
1
7 7
```

然后输出 `7 8` 并刷新。下一次只会收到对手新的一步，不会重复初始化。

## 路墙棋 Quoridor

棋盘为 9 × 9 个棋格，棋格坐标 `X,Y` 均为 `0..8`，X 向右、Y 向下。席位 0 从 `(4,0)` 出发并先手，席位 1 从 `(4,8)` 出发。双方各有十面墙，率先抵达对面目标边的任意棋格即胜：席位 0 的目标是 `Y=8`，席位 1 的目标是 `Y=0`。双方各完成 100 步、整局 200 步仍无人获胜时，以 `move_limit` 结束。

启动时标准输入为一行：

```text
1 S
```

移动棋子时输出三个整数：

```text
0 X Y
```

放墙时输出四个整数：

```text
1 X Y O
```

墙的中心是棋格之间的内部交叉点，因此墙坐标 `X,Y` 均为 `1..8`。`O=0` 是竖墙，`O=1` 是横墙。例如竖墙 `(4,2,0)` 阻断 `(3,1)↔(4,1)` 与 `(3,2)↔(4,2)`；横墙 `(4,2,1)` 阻断 `(3,1)↔(3,2)` 与 `(4,1)↔(4,2)`。接收对手行动时，输入与上述输出格式相同。

每回合只能移动或放一面墙：

- 通常向上、下、左、右移动一格，不能穿墙、出界或与对手同格。
- 对手在无墙相隔的相邻格时，若其正后方在棋盘内且无墙，允许直线跳过对手。
- 只有对手正后方出界或被墙挡住时，才允许跳到对手两侧；对应侧边也必须无墙。双方本身隔着墙时，不能借对手跳跃。
- 新墙不能与已有墙交叉或重叠。横墙 `(4,2,1)` 与 `(5,2,1)` 重叠，与竖墙 `(4,2,0)` 交叉；横墙 `(4,2,1)` 与 `(6,2,1)` 仅端点相接，允许放置。
- 放墙后，双方都必须仍有通向各自目标边的路径。检查路径时只考虑墙，对手棋子不作为永久障碍。墙数为零时不能再放墙。

## 输出刷新与资源限制

C++ 可以使用 `std::endl`，或在写入 `\n` 后显式 `std::flush`：

```cpp
std::cout << x << ' ' << y << std::endl;       // 五子棋
std::cout << "0 " << x << ' ' << y << '\n' << std::flush; // 路墙棋移动
std::cerr << "search finished\n";            // 调试日志
```

运行器默认限制为每步主进程 CPU **100 ms**、单方主进程整局累计 CPU **5 s**、每步墙上时间 **1 s**、内存 **256 MiB**、单步标准输出（含换行）**64 字节**。CPU、内存及输出上限由运行器的 `ProcessLimits` 配置；每步墙上时间由 `Turn()` 的超时参数配置，界面设置可调整墙上超时。主进程在回合之间被暂停，等待对手时不消耗该进程的活动 CPU 时间预算；子进程的 CPU 和暂停范围见 `architecture.md`。缺少换行、超时、异常退出或非法行动会结束该程序的对局，并在界面显示诊断。

CompIntel3 是运行本地程序的开发工具，使用 Windows 进程资源限制；它**不是安全沙箱**。编译出的 Player 具有本机用户权限。使用可信源代码进行本地练习。

完整独立示例见仓库的 `examples/gomoku.cpp` 和 `examples/quoridor.cpp`，它们不依赖 CompIntel3 的内部头文件。
